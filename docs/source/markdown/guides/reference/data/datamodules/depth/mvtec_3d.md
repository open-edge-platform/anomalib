# MVTec 3D Datamodule

```{warning}
Automatic downloads are temporarily disabled because upstream links return HTTP 404.
Download the dataset from the [official MVTec 3D-AD page](https://www.mvtec.com/research-teaching/datasets/mvtec-3d-ad)
and extract it under `root`, so that `root/category/train` and `root/category/test` exist.
Existing local datasets remain supported. Restoration is tracked in [#3892](https://github.com/open-edge-platform/anomalib/issues/3892).
```
