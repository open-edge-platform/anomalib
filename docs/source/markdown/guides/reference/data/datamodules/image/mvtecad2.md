# MVTecAD2 Datamodule

```{warning}
Automatic downloads are temporarily disabled because upstream links return HTTP 404.
Download the dataset from the [official MVTec AD 2 page](https://www.mvtec.com/research-teaching/datasets/mvtec-ad-2)
and extract it under `root`, so that `root/category/train` and the selected test directory (for example, `root/category/test_public`) exist.
Existing local datasets remain supported. Restoration is tracked in [#3892](https://github.com/open-edge-platform/anomalib/issues/3892).
```
