# MVTecLOCO Datamodule

```{warning}
Automatic downloads are unavailable, and the previous upstream download link returns HTTP 404.
Download the dataset from the [official MVTec LOCO AD page](https://www.mvtec.com/research-teaching/datasets/mvtec-loco-ad)
and extract it under `root`, so that `root/category/train`, `root/category/validation`, and `root/category/test` exist.
Existing local datasets remain supported. Download support is tracked in [#3892](https://github.com/open-edge-platform/anomalib/issues/3892).
```
