# VAD Datamodule

```{note}
Automatic downloads are unavailable for VAD.
Download the dataset from the [official VAD Google Drive link](https://drive.google.com/file/d/1sWNZCUnb2u4hcr6ak7gjpwsm6jtx6IF1/view?usp=sharing)
(listed at [abc-125/segad](https://github.com/abc-125/segad)) and extract it under `root`,
so that `root/category/train` and `root/category/test` exist.
```
